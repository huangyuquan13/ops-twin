# 智维方舟 (Ops-Twin) - 今日攻坚计划 (Stage 3: 资产中心)

**日期**: 2026-05-07
**战略目标**: 从“纯展示”跨越到“管理即配置”。彻底打通物理资产与逻辑业务的界限，为后续的自动化演练提供数据基石。

## 核心任务一：物理资产台账 (Physical Asset Ledger)
**目标**: 建立 3D 大屏与后端数据的 CRUD 枢纽。
**具体工作**:
1. **后端 API**: 完善 `AssetController` 中对 `asset_host` 的增删改查分页接口。
2. **前端页面**: 开发 `src/views/asset/PhysicalHost.vue`。
3. **亮点功能**: 
   - 带有复杂筛选器的高级表格。
   - 在新增/编辑主机时，能够直接配置 `cabinet_id` (归属机柜) 和 `rack_pos` (U位插槽)。
   - **闭环验证**: 在这里修改主机的机柜归属或插槽位置后，切回 3D 大屏，对应的发光刀片应该立刻改变位置。

## 核心任务二：逻辑服务映射 (Logical Service Mapping)
**目标**: 引入 `Vue Flow`，实现业务系统的可视化拓扑组装。
**具体工作**:
1. **后端 API**: 新增 `ServiceController`，实现 `asset_service` (逻辑系统表) 与 `service_host_map` (系统-主机绑定关联表) 的数据交互。
2. **前端页面**: 开发 `src/views/asset/LogicMapping.vue`。
3. **亮点功能**:
   - 左侧：可拖拽的物理服务器节点列表 (Node List)。
   - 右侧：无穷大的画布 (Vue Flow Canvas)。
   - 操作：将服务器拖入画布，连线组合成“支付系统”、“订单系统”，一键保存拓扑关系到数据库。

- 保证前后端数据类型严格对齐。
- 每完成一个核心任务，立即进行联调验证。
