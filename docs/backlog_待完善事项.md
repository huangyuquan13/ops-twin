## 📊 一、看板中心 - 监控数据真实化

### ⚠️ 问题：ECharts 监控指标为模拟数据
- **位置**: `src/views/dashboard/index.vue`
- **现状**: CPU 使用率、内存占用、以及出入网流量波动折线图，当前使用的是前端 `setInterval` + `Math.random()` 生成的假数据。看上去有动感，但对运维决策毫无价值。
- **根本原因**: 真实的监控指标（尤其是按时间序列变化的网络流量）属于**时序数据 (Time-Series Data)**，不适合存储在 MySQL 这类关系型数据库中。MySQL 存时序数据有严重的写入放大和查询性能问题。

**推荐改造方案**：

| 方案 | 技术选型 | 说明 |
|---|---|---|
| **轻量方案** | InfluxDB (开源时序数据库) | 专为监控场景设计，写入性能极强，自带 Grafana 看板 |
| **云原生方案** | Prometheus + Grafana | 业界最主流的监控告警体系，可与 k8s 深度集成 |
| **极简方案** | MySQL 按天/按小时分表 | 最容易实现，但查询性能有上限，适合数据量不大的场景 |

**改造步骤（待实施）**：
1. 引入 InfluxDB 或 Prometheus 作为数据源。
2. 在 Spring Boot 中接入 `Micrometer` 采集 JVM 和主机指标，并定时推送。
3. 前端将 `setInterval` 替换为 WebSocket 订阅，实时接收后端推送的真实指标流。
4. 将 `src/views/dashboard/index.vue` 中所有 mock 数据函数全部替换为真实 API 调用。

## 👤 二、系统管理 - 用户头像存储方案优化

### ⚠️ 问题：头像以文件形式存储在服务器本地，不具备可扩展性
- **位置**: `src/views/system/user.vue` / 后端 `UserController.java` 头像上传接口
- **现状**: 用户上传头像后，图片文件被保存到 Spring Boot 服务器本地磁盘的某个目录（如 `/uploads/avatar/`），数据库只存文件路径。
- **核心问题**:
  - **单点故障**：服务器重启、迁移、扩容时，本地文件会丢失或无法同步到新实例。
  - **扩展性差**：如果有大量用户同时上传，磁盘 IO 会成为瓶颈；水平扩展（多台服务器）时，A 服务器上传的头像，B 服务器无法访问。
  - **运维成本高**：需要人工管理磁盘空间和文件备份。

**推荐改造方案（待实施）**：

| 方案 | 技术选型 | 说明 |
|---|---|---|
| **生产首选** | 阿里云 OSS / 腾讯云 COS | 国内云存储标准，99.999% 可靠性，带 CDN 加速，按用量付费 |
| **私有化部署** | MinIO | 完全兼容 S3 协议的开源对象存储，适合内网/离线环境 |
| **极简 Base64** | 直接存入数据库 `longtext` 字段 | 最简单但最不规范，头像文件较大时会严重拖慢数据库查询 |

**改造步骤（待实施，需先了解 Java 文件上传与 OSS SDK 相关知识）**：
1. 引入对应 OSS SDK 依赖（如 `aliyun-sdk-oss`）。
2. 在 Spring Boot 中创建 `OssService`，封装上传/删除接口，将本地磁盘操作替换为云端 API 调用。
3. 数据库中存储的不再是本地路径，而是 **OSS 的公开访问 URL**（如 `https://my-bucket.oss-cn-hangzhou.aliyuncs.com/avatar/user_123.jpg`）。
4. 前端 `<el-avatar :src="...">` 无需任何改动，直接使用 URL 即可。
5. 额外优化：对同一用户的旧头像执行删除操作，避免产生大量冗余文件造成存储浪费。

## 🔒 三、系统管理 - 权限体系精细化

### ⚠️ 问题：当前 RBAC 只控制菜单，未控制按钮级别权限
- **位置**: `src/views/system/` 相关页面
- **现状**: 角色绑定控制侧边栏菜单的显示与隐藏，但页面内的"新增"、"删除"、"编辑"等按钮对所有登录用户均可见。
- **目标**: 实现按钮级权限（如：只读角色可以查看列表，但看不到"删除"按钮）。

**改造思路（待实施）**：
- 前端实现一个全局自定义指令 `v-permission="['asset:host:delete']"`。
- 后端在权限接口中返回当前用户拥有的权限点列表。
- 指令检查权限点列表，若不存在则将对应元素从 DOM 中移除。
