# 智维方舟 (Ops-Twin) 项目总实施计划 (架构师视界)

## 核心路线图 (基于侧边栏 4 大中枢架构)

### [x] Stage 1: 基础设施与看板中心 (已完成)
- [x] **底层基座**: Vue3 + SpringBoot 脚手架，MD5加密，Pinia 持久化。
- [x] **3D 孪生大屏**: InstancedMesh 性能优化，L1/L2/L3 物理机柜与插槽真实解耦穿透。
- [x] **效能大盘分析**: 对接 MySQL 实时汇总总算力、总内存、告警占比，ECharts 响应式渲染。

### [▶] Stage 2: 资产中心 (当前进行中)
- [x] **物理资产台账**: 完整的 `asset_host`与`asset_cabinet` CRUD，强化了空间冲突与唯一性拦截，作为 3D 渲染和逻辑拓扑的绝对数据源头。
- [▶] **逻辑服务映射**: 引入 Vue Flow，支持拖拽将零散的物理服务器组装为“逻辑业务系统”（如支付系统），实现物理架构到业务架构的转换。

### [ ] Stage 3: 任务中心 (自动化演练引擎)
- [ ] **预案方案库**: 运维预案的 JSON 编排与存储。
- [ ] **演练工作流**: 基于状态机的容灾任务执行 (如下线故障机器、切换备用机)。
- [ ] **实时监控终端**: 类似 Xterm.js 的控制台，WebSocket 实时拉取演练流水线日志。

### [ ] Stage 4: 系统管理 (安全与审计)
- [ ] **用户中心**: 账号、密码、个人资料管理。
- [ ] **权限配置**: 动态路由菜单、操作按钮级的 RBAC 权限隔离。
- [ ] **操作审计**: 拦截并记录敏感操作，生成安全审计日志。
