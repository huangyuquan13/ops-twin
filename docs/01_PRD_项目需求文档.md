# 智维方舟 (Ops-Twin) - 3D 数据中心数字孪生与自动化平台

## 1. 项目愿景：从“管理后台”到“运维中枢”
我们现在的目标是把项目从简单的“增删改查”升级为具有**高度业务关联性**的运维产品。界面不再是孤立的，而是相互影响的联动体系。

## 2. 深度优化的功能模块 (极客化、专业化)

### 2.1 看板中心 (决策层，已完成 ✅)
*   **3D 沉浸式数字孪生大屏**：
    *   **多层级拓扑穿透**：L1 机房层 -> L2 机架层 -> L3 硬件标牌。根据 `cabinet_id` 和 `rack_pos` 实现 100% 物理级真实渲染。
    *   **热力图模式**：一键切换 3D 场景材质，根据真实负载分布渲染温度场。
*   **效能大盘分析**：对接后台真实资产数据，ECharts 渲染集群物理总算力、总内存及饼图分布。

### 2.2 资产中心 (元数据层，当前攻坚目标)
*   **物理资产台账**：所有 3D 渲染和拓扑的唯一数据源头。支持 CRUD，并在前端支持直接配置 `cabinet_id` (机柜) 和 `rack_pos` (U位)。
*   **逻辑服务映射**：基于 Vue Flow 的“服务拓扑树”。支持拖拽式地将零散物理节点绑定为“支付系统”、“订单系统”等逻辑集群。

### 2.3 任务中心 (控制层)
*   **演练工作流**：可视化状态机驱动的容灾任务执行 (如：1.注入故障 -> 2.等待检测 -> 3.执行自愈)。
*   **预案方案库**：沉淀常见的运维预案（如：缓存雪崩熔断）。
*   **实时监控终端**：基于 WebSocket + Xterm.js 的控制台，实时滚动展示流水线底层的执行日志。

### 2.4 系统管理 (安全基座)
*   **权限配置 (RBAC 3.0)**：不仅控制侧边栏，还要精确到每一个操作按钮的可见性。
*   **操作审计**：记录拦截关键操作指令，形成安全可溯源的审计日志。

---

## 3. 技术挑战与简历亮点 (整理给面试官看)

1.  **3D 渲染性能优化**：如何在网页端流畅加载几百个服务器模型？(使用 **InstancedMesh** 实例化渲染技术)。
2.  **前端状态机驱动的任务流**：使用 Vue3 结合 XState 或简单的自定义状态机，管理复杂的容灾自动化流程。
3.  **响应式大屏适配**：利用 CSS 的 `scale` 方案，实现无论在几寸显示器上，3D 画布和 UI 组件都能完美等比缩放。
4.  **大规模双向数据通信**：后端 SpringBoot 的日志流如何不卡顿地实时刷新在 Vue 组件上（涉及异步缓冲区优化）。
