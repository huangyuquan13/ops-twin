# 智维方舟 (Ops-Twin) - 3D 数据中心数字孪生与自动化平台

## 1. 项目愿景：从“管理后台”到“运维中枢”
我们现在的目标是把项目从简单的“增删改查”升级为具有**高度业务关联性**的运维产品。界面不再是孤立的，而是相互影响的联动体系。

## 2. 深度优化的功能模块 (极客化、专业化)

### 2.1 看板中心 (决策层，已完成 ✅)
*   **3D 沉浸式数字孪生大屏**：
    *   **多层级拓扑穿透**：L1 机房层 -> L2 机架层 -> L3 硬件标牌。根据 `cabinet_id` 和 `rack_pos` 实现 100% 物理级真实渲染。
    *   **热力图模式**：一键切换 3D 场景材质，根据真实负载分布渲染温度场。
*   **效能大盘分析**：对接后台真实资产数据，ECharts 渲染集群物理总算力、总内存及饼图分布。

### 2.2 资产中心 (元数据层，已完成)
*   **物理资产台账**：所有 3D 渲染和拓扑的唯一数据源头。支持 CRUD，并在前端支持直接配置 `cabinet_id` (机柜) 和 `rack_pos` (U位)。
*   **逻辑服务映射**：基于 Vue Flow 的“服务拓扑树”。支持拖拽式地将零散物理节点绑定为“支付系统”、“订单系统”等逻辑集群。

### 2.3 任务中心 (控制层，已完成 ✅)
*   **任务总览仪表盘**：KPI 统计卡片 + 预案列表 + 快捷编排/执行/设定方案入口。
*   **演练工作流**：异步执行引擎驱动的容灾任务模拟（支持 `steps_json` 编排，支持手动终止）。
*   **预案方案库**：支持 DRILL/FAILOVER/SCALE 三大类预案的 CRUD + 服务联动。
*   **实时监控终端**：基于 WebSocket + Xterm 风格的控制台，秒级日志流推送 + 终止命令按钮。

### 2.4 系统管理 (安全基座，已完成 ✅)
*   **用户中心**：账号 CRUD + 头像上传 + 按钮权限控制。
*   **权限配置 (RBAC)**：`sys_role` + `sys_role_permission` 两张表，角色管理 + el-tree 菜单/按钮权限勾选分配，侧边栏动态渲染。
*   **操作审计**：6 种事件类型（新增/编辑/删除/执行预案 + 修改权限），持久化 `audit_event` 表。

## 3. 技术挑战与简历亮点 (整理给面试官看)

1.  **3D 渲染性能优化**：如何在网页端流畅加载几百个服务器模型？(使用 **InstancedMesh** 实例化渲染技术，8 机柜 60 主机零卡顿)。
2.  **真实异步执行引擎**：后台线程解析 steps_json 步骤编排，根据 hostname 查 asset_host 表动态修改 status (1/2/3)，支持三种演练类型 (DRILL/FAILOVER/SCALE) 的不同行为策略 — DRILL 执行后自动恢复主机状态，FAILOVER 持久化变更并迁移服务绑定，SCALE 动态调整服务-主机映射。
3.  **3D 大屏实时联动**：策略页触发演练 → 3D 孪生大屏相机自动飞行至目标机柜、自动进入 L2 层级、自动切换热力模式 → 主机 LED 脉冲动画实时变色 (绿→黄→红) + 刀片盒发光高亮 + 机柜线框变色 → 浮动迷你终端面板自动弹出，展示与终端页面同步的日志流 → DRILL 执行结束自动恢复所有视觉效果。
4.  **双通道 WebSocket 实时通信**：`/ws/task/log/{id}` 通道推送 Xterm 风格终端日志流 (INFO/WARN/ERROR 语义着色) + `/ws/dashboard/events` 通道广播结构化 3D 事件 JSON (HOST_STATUS_CHANGE / CABINET_HIGHLIGHT / CAMERA_FLY_TO)，前后端双向实时联动。
5.  **前后端状态机驱动的任务流**：使用 Vue3 结合自定义状态机，管理复杂的容灾自动化流程（PENDING→RUNNING→SUCCESS/FAILED/CANCELLED）。
6.  **响应式大屏适配**：利用 CSS 的 `scale` 方案，实现无论在几寸显示器上，3D 画布和 UI 组件都能完美等比缩放。
7.  **sessionStorage 跨页状态恢复**：浮动终端"返回大屏"功能，通过 sessionStorage 保存 L2 层级/热力模式/相机位置等全部导航状态，从终端页返回后无缝恢复。
8.  **JWT + bcrypt 安全认证**：jjwt 0.12.5 生成验证 Bearer Token，bcrypt 哈希存储密码，旧 MD5 密码登录时自动迁移，CORS 集中管控。

## 4. 安全与运维体系

### 4.1 身份认证 (JWT + bcrypt)
- **真实 JWT 认证**：使用 jjwt 0.12.5 库生成和验证 JWT，Bearer Token 模式
- **bcrypt 密码加密**：新用户密码使用 bcrypt 哈希存储，旧 MD5 密码登录时自动迁移为 bcrypt
- **登录接口** `POST /api/auth/login`：验证用户名和密码，返回 `{ token: “eyJhbGciOiJIUzI1NiJ9...” }`
- **请求拦截**：前端 Axios 拦截器自动附加 `Authorization: Bearer <token>` 头

### 4.2 全局 CORS 安全管控
- **集中管控**：所有 CORS 配置集中在 `WebConfig.java`，不分散在各 Controller 的 `@CrossOrigin` 注解
- **策略**：允许指定前端源的跨域请求，统一管理允许的方法、头和凭证传递

### 4.3 AOP 操作审计
- **`@AuditLog` 注解**：自定义方法级注解，标注在写入操作（创建/删除/执行预案等）
- **`AuditLogAspect` 切面**：环绕通知自动拦截，提取操作人（从 Authorization 头解析 JWT），记录操作类型、描述和结果到 `audit_event` 表
- **事件类型**：LOGIN / EXECUTE_PLAN / DELETE_PLAN / SAVE_PLAN 等 6 种

### 4.4 RBAC 权限控制
- **角色管理**：`sys_role` 表，管理员可创建角色并分配菜单/按钮权限
- **权限树**：`sys_permission` 表存储菜单（type=1）和按钮（type=2），el-tree 可视化勾选
- **动态侧边栏**：前端根据当前用户角色的权限码动态渲染菜单
- **按钮级权限**：`v-if` 检查 `userStore.permissions` 控制增删改按钮显隐

### 4.5 真实执行引擎 — 三种演练类型行为

| 演练类型 | 主机状态变更 | 执行后行为 | service_host_map | 预案状态 |
|---|---|---|---|---|
| **DRILL (演练)** | status 1→3 (宕机) | 执行结束后**自动恢复**为 1(健康)，3D LED 恢复绿色 | 不变 | 保持启用 |
| **FAILOVER (故障切换)** | status 1→3 (宕机) | **持久化**不恢复，将宕机主机的服务绑定迁移到备用主机 | 动态修改 host_id | 自动禁用 (status=0) |
| **SCALE (弹性伸缩)** | 不直接修改主机状态 | 动态调整服务-主机映射关系 | 增加或移除绑定 | 自动禁用 (status=0) |

**预案重置**：`POST /api/task/plan/reset/{planId}` 可将 FAILOVER/SCALE 执行后的预案恢复为启用状态，并还原服务绑定关系。
