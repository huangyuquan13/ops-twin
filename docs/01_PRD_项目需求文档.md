# 智维方舟 (Ops-Twin) - 3D 数据中心数字孪生与自动化平台

## 1. 项目愿景：从“管理后台”到“运维中枢”
我们现在的目标是把项目从简单的“增删改查”升级为具有**高度业务关联性**的运维产品。界面不再是孤立的，而是相互影响的联动体系。

## 2. 深度优化的功能模块 (极客化、专业化)

### 2.1 3D 沉浸式数字孪生大屏 (已完成 ✅：100% 真实数据驱动)
*   **多层级拓扑穿透 (物理级映射)**：
    *   **L1 机房层**：上帝视角看所有机柜。根据 `cabinet_id` 自动将主机聚合为物理机柜。
    *   **L2 机架层**：点击机柜，模型平滑放大。精确根据数据库 `rack_pos` 字段点亮具体的 U 位插槽，空插槽显示为盲板。
    *   **L3 硬件细节**：点击特定发光服务器，在 3D 空间中悬浮展示真实 `hostname`、物理算力及负载情况的“真全息数字标牌”。
*   **热力图模式 (Thermal Map)**：一键切换 3D 场景材质，根据真实或预测的负载分布，对机柜插槽中的机器动态渲染变色（跳过空盲板）。

### 2.2 资产与逻辑拓扑管理中心 (管理即配置)
*   **物理资产管理**：管理服务器、机柜、网络交换机的硬件参数。
*   **逻辑服务映射 (亮点)**：这不仅是权限树，而是 **“服务拓扑树”**。
    *   例如：定义一个“支付系统”，它由 3 个 Nginx 节点和 2 个数据库节点组成。
    *   功能：支持拖拽式地调整服务与硬件的绑定关系。

### 2.3 容灾演练编排工作站 (可视化工作流)
*   **编排式任务设计**：不再是写死一个脚本名。
    *   支持可视化配置任务步骤：`1. 注入故障` -> `2. 等待5秒检测` -> `3. 执行自愈脚本` -> `4. 恢复流量`。
*   **预案仓库**：内置常见的运维预案（如：预防DDoS攻击流控、数据库主从切换、缓存雪崩熔断）。

### 2.4 全球自动化任务调度监控 (执行现状)
*   **流式执行终端 (Ultra-Terminal)**：
    *   **多终端分屏**：支持同时监控 2-3 台服务器的执行日志，屏幕像黑客帝国一样分块滚动。
    *   **执行轨迹图**：用一个进度步进器（Steps）展示当前流水线跑到了哪一步，哪一步失败了可以点红叉查看详细堆栈。

### 2.5 运维知识库与自愈记录 (新增模块：增加数据沉淀)
*   **故障追溯分析**：自动汇总过去执行过的容灾任务。
*   **分析看板**：用 Echarts 展示故障发生的频率、自愈成功率、平均恢复时长（MTTR）。这直接拉高了项目的管理层视角。

### 2.6 动态权限与审计枢纽 (安全套件)
*   **RBAC 3.0**：不仅控制侧边栏，还要控制到 **“3D 场景内的具体动作”**。
*   **操作审计日志**：记录谁在什么时间，通过 3D 界面对哪台机器下发了什么致命指令。这是金融级、运维级项目必备的严谨性。

## 3. 技术挑战与简历亮点 (整理给面试官看)

1.  **3D 渲染性能优化**：如何在网页端流畅加载几百个服务器模型？(使用 **InstancedMesh** 实例化渲染技术)。
2.  **前端状态机驱动的任务流**：使用 Vue3 结合 XState 或简单的自定义状态机，管理复杂的容灾自动化流程。
3.  **响应式大屏适配**：利用 CSS 的 `scale` 方案，实现无论在几寸显示器上，3D 画布和 UI 组件都能完美等比缩放。
4.  **大规模双向数据通信**：后端 SpringBoot 的日志流如何不卡顿地实时刷新在 Vue 组件上（涉及异步缓冲区优化）。
